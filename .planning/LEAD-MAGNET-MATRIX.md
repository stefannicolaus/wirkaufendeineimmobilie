## STRATEGIE-KERN

Statt generischer PDFs: **Individuelle Guides basierend auf Situation des Nutzers.**
- Google-Suche bringt Traffic auf SEO-optimierte Landing Page
- Nutzer beantwortet 5-8 Fragen (Tally-Formular)
- Guide wird personalisiert generiert (Segment-Split → Daten-Insert → Voll-Personalisiert)
- Lead ist qualifiziert: Situation, Objekt, Dringlichkeit bekannt
- Follow-up: Joachim ruft an mit komplettem Kontext

### V1: Erbengemeinschaft — Raus aus der Blockade [PRIO 1]

**Titel:** "Erbengemeinschaft & Immobilie — 7 Wege aus der Blockade"
**Pain:** Geschwister blockiert seit Jahren, Kosten laufen, nichts geht voran
**SEO-Keywords:** "Erbengemeinschaft Haus verkaufen einer will nicht", "Erbengemeinschaft Immobilie verkaufen"
**Format:** PDF 12-15 Seiten
**Zielgruppe:** Erben in blockierter EG, 45-70 Jahre

**Intake-Formular (6 Felder):**
1. Wie viele Erben? (2 / 3 / 4+ / weiss nicht)
2. Wer blockiert? (Geschwister / Ehepartner/in / Enkel / andere)
3. Seit wann blockiert? (< 6 Monate / 6-24 Monate / > 2 Jahre)
4. Objekt-Typ? (Wohnung / Haus / Grundstueck)
5. PLZ des Objekts
6. E-Mail

**Was wird individualisiert:**

| Eingabe | Personalisierung im Guide |
|---------|--------------------------|
| Anzahl Erben | Aufteilung des Erloes pro Erbe berechnet |
| Wer blockiert | Rechtliche Hebel unterschiedlich: Geschwister → Abschichtung/Erbteilverkauf. Ehepartner → Zugewinnausgleich relevant |
| Blockade-Dauer < 6 Mo. | Eskalationsstufe 1: Mediations-Tipps, Kommunikationsvorlagen |
| Blockade-Dauer 6-24 Mo. | Eskalationsstufe 2: Anwaltliche Aufforderung, Angebotsverfahren als Loesung |
| Blockade-Dauer > 2 Jahre | Eskalationsstufe 3: Teilungsversteigerung vs. Angebotsverfahren Vergleich |
| PLZ | Zustaendiges Nachlassgericht, empfohlene Fachanwaelte, Verbraucherzentrale in der Region |
| Alle Daten kombiniert | **Kostenrechner:** "Ihre Blockade kostet Sie X EUR/Monat" (Grundsteuer + Versicherung + Hausgeld + Wertverlust). Beispiel: 52qm Leipzig, 18 Monate = 7.940 EUR bisher verbrannt |
| Alle Daten kombiniert | **Marktwert-Schaetzung:** "Ihre Wohnung ist aktuell ca. X EUR wert. Im Angebotsverfahren: Y EUR (+12%). Ihr Anteil: Z EUR." |

**Guide-Struktur (14 Seiten):**
1. S.1-2: INDIVIDUELL — Ihre Situation (Eskalationsstufe + Kostenrechner)
2. S.3-9: ALLGEMEIN + PRIORISIERT — 7 Wege aus der Blockade (mit individueller Empfehlung welche Wege fuer DIESE Situation am besten passen)
3. S.10-11: INDIVIDUELL — Lokale Kontakte (Nachlassgericht, Anwaelte, Beratung)
4. S.12-13: INDIVIDUELL — Was Ihre Wohnung auf unserer Plattform bringen koennte (Marktwert, Angebotsverfahren-Aufschlag, Anteil pro Erbe)
5. S.14: CTA — Kostenlose Erstberatung buchen

## PERSONALISIERUNGS-LEVEL

| Level | Aufwand | Was passiert | Technik | Wann |
|-------|---------|-------------|---------|------|
| **L1: Segment-Split** | Niedrig | 2-3 Varianten pro Guide | Tally → Weiche → verschiedene PDF-Links | Sofort (MVP) |
| **L2: Daten-Insert** | Mittel | Individuelle Zahlen im Guide | Make.com + Claude API → dynamisches PDF | Ab 50+ Downloads/Monat |
| **L3: Voll-Personalisiert** | Hoch | Komplett generierter Guide | Claude API → Typst/PDF-Pipeline | Ab Produkt-Market-Fit |

**Start-Empfehlung:** L1 fuer alle Guides. L2 fuer V1 (Erbengemeinschaft) und V4 (Sanieren/Verkaufen) weil diese am meisten von individuellen Zahlen profitieren.

## LEAD-QUALIFIZIERUNG

Jeder Guide-Download liefert:
1. **E-Mail** — fuer Follow-up-Sequenz (3-5 E-Mails ueber 2 Wochen)
2. **Situation** — Segment + Pain (qualifiziert den Lead)
3. **PLZ/Stadtteil** — geografische Qualifizierung (Leipzig = hot, andere = nurture)
4. **Objektdaten** — qm, Baujahr, Zustand (bei Verkaeufer-Guides)
5. **Dringlichkeit** — wie lange schon im Problem?

**Ergebnis fuer Joachims Anruf:** Kein Kaltanruf, sondern:
"Frau Mueller, Sie haben unseren Guide zur Erbengemeinschaft heruntergeladen. 3 Erben, 18 Monate Blockade, 52qm in Leipzig. Wie kann ich Ihnen helfen?"

## ROI-RECHNER (Standalone-Tool)

**Konzept:** Interaktives Web-Tool auf der Plattform — kein PDF, sondern Live-Rechner.
**Kein Wettbewerber hat das.** Groesste Differenzierung.

**Inputs:**
1. Kaufpreis (oder PLZ + qm fuer Schaetzung)
2. Sanierungskosten (oder Zustand 1-5 fuer Schaetzung)
3. Eigenleistung moeglich? (Gewerk waehlen)
4. Finanzierungsart (EK / Bank / Mix)
5. Haltedauer (Monate)

**Outputs:**
- Gesamtkosten (Kauf + NK + Sanierung + Finanzierungskosten + Haltekosten)
- Erwarteter Verkaufspreis (basierend auf qm-Preis saniert)
- Brutto-Gewinn
- Netto-Gewinn (nach Steuern, abhaengig von Haltedauer + 3-Objekt-Status)
- ROI auf Eigenkapital
- Vergleich: "Wenn Sie Elektriker sind und die Elektrik selbst machen: +X EUR Ersparnis"

**Lead-Capture:** "Ergebnis als PDF speichern" → E-Mail-Abfrage
