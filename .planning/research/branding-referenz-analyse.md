## Synthese: Gemeinsame Patterns der "Wir kaufen"-Marken

### Visuelles

| Pattern | Verbreitung |
|---------|-------------|
| Orange/Gruen/Blau als Primaerfarben (warm + aktiv) | 4/4 |
| Sans-Serif Fonts (Open Sans, Lato, Outfit, Helvetica) | 4/4 |
| Weisser/heller Hintergrund | 4/4 |
| Formular oder Suchfeld direkt im Hero | 3/4 |
| Kategorie-Kacheln mit Icons/Bildern | 3/4 |
| 3-Schritte-Prozess visuell dargestellt | 4/4 |
| Trust-Badges prominent auf Homepage | 4/4 |

### Tonalitaet + Ansprache

| Pattern | Verbreitung |
|---------|-------------|
| **Du-Ansprache** | **4/4** (momox erst seit 2026) |
| Einfachheit als Kernversprechen | 4/4 |
| "Schnell", "einfach", "fair" als Trigger-Woerter | 4/4 |
| Nachhaltigkeit als Wert | 3/4 |
| "Jetzt verkaufen" als CTA-Standard | 3/4 |

### Trust-Architektur

| Signal-Typ | Beispiele |
|------------|----------|
| Bewertungsportale | Trustpilot, Trusted Shops |
| Test-Siegel | Stiftung Warentest, CHIP |
| Medien-Logos | "Bekannt aus" RTL, Galileo, Focus |
| Zahlen | "5 Mio. Kunden", "200+ Filialen" |
| Kundenstimmen | Name + Ort + Zitat |
| Prozess-Transparenz | 3-Schritte-Grafik |

### Was diese Marken SOFORT erkennbar macht

1. **Formular-First:** Kein "Willkommen"-Text, sondern sofort Eingabefeld/Suchfeld
2. **Aktionsfarben:** Orange, Gruen, Rot auf CTAs -- laut, auffaellig, dringlich
3. **Du-Ansprache:** Informell, barrier-abbauend, "wie ein Kumpel"
4. **Zahlenbeweis:** Millionen-Kunden, Tausende-Bewertungen, Hunderte-Standorte
5. **Funktionales Design:** Zweckmaessig, nicht aesthetisch -- Conversion > Beauty
6. **3-Schritte-Versprechen:** "So einfach geht's" ist der universelle Trust-Mechanismus

## Delta-Analyse: Was muss wirkaufendeineimmobilie.de ANDERS machen?

### Das Problem: Immobilien sind KEINE Gebrauchtwaren

| Dimension | Gebrauchtwaren (Auto, Handy) | Immobilien |
|-----------|------------------------------|------------|
| Emotionaler Wert | Gering (Gebrauchsgegenstand) | Hoch (Lebenswerk, Erbe, Erinnerungen) |
| Transaktionsvolumen | 500-30.000 EUR | 50.000-500.000 EUR |
| Entscheidungszeit | Minuten bis Tage | Wochen bis Monate |
| Vertrauensbedarf | Mittel (Bewertungen reichen) | Sehr hoch (persoenliche Beratung erwartet) |
| Komplexitaet | Gering (Zustand + Marke) | Hoch (Lage, Zustand, Recht, Finanzierung) |
| Wiederholungsfrequenz | Mehrfach im Leben | 1-3x im Leben |

### Konkreter Design-Abstand

#### 1. FONT: Kein Open Sans / Lato / Outfit
- Gebrauchtwaren-Plattformen nutzen generische Sans-Serifs = "billig + schnell"
- Immobilien brauchen: **Serif oder Premium-Sans** (wie E&V: eigene Schrift)
- Empfehlung: DM Serif Display (Headlines) + DM Sans (Body) oder aehnliche Kombination mit Charakter

#### 2. FARBE: Kein Orange / Grelles Gruen
- Orange = Dringlichkeit, Schnelligkeit, "Schnaeppchen" -- FALSCH fuer Immobilien
- Grelles Gruen = Oeko, Recycling -- zu nah an Gebrauchtwaren
- Empfehlung: **Gedaempftes Gruen** (Wertsteigerung, Wachstum, Nachhaltigkeit) + **Dunkles Blau oder Anthrazit** (Vertrauen, Substanz) + **Warmer Akzent** (Gold, Kupfer, warmes Beige -- nicht Orange)
- Background: Warm-Weiss wie E&V (`#FCFAF5` statt `#FFFFFF`) = sofort edler

#### 3. HERO: Kein Formular-First
- Gebrauchtwaren: Formular IST der Hero (sofort scannen/eingeben)
- Immobilien: **Emotion zuerst, dann Aktion**
- Empfehlung: Hochwertiges Immobilienbild (vorher/nachher oder Potenzial-Visualisierung) + klare Headline + DANN dezentes Bewertungsformular
- Alternative: Split-Screen (links Bild, rechts kurzes Formular)

#### 4. ANSPRACHE: Du ODER Sie -- bewusst waehlen
- Alle Gebrauchtwaren-Plattformen: Du (Barriere senken)
- E&V: Sie (Respekt, Premium)
- brown2green Zielgruppe: Eigentuemer sanierungsbeduerftiger Wohnungen
  - Oft aelter, oft geerbt, oft ueberfordert
  - **Empfehlung: "Sie"** -- Respekt vor der Lebenssituation, Serioesitaet
  - ABER: Nicht steif wie E&V. Warm + persoenlich + respektvoll.

#### 5. TRUST-SIGNALE: Andere Kategorie
- Gebrauchtwaren: Trustpilot-Sterne, Medien-Logos, Kundenzahlen
- Immobilien brauchen:
  - **Persoenliche Expertise:** Gesichter, Namen, Qualifikationen des Teams
  - **Lokale Verankerung:** "Wir kennen Leipzig" statt "200+ Standorte"
  - **Prozess-Transparenz:** Nicht 3 Schritte, sondern detaillierter Ablauf mit Zeitplan
  - **Referenz-Objekte:** Vorher/Nachher mit konkreten Zahlen
  - **Rechtliche Sicherheit:** Notarielle Abwicklung, transparente Vertraege
  - **KEINE Trustpilot-Widgets** -- wirkt bei Immobilien unserioes

#### 6. CTA-TEXT: Kein "Jetzt verkaufen"
- "Jetzt verkaufen" = Druck, Eile -- FALSCH bei Immobilien
- Empfehlung: **"Kostenlose Bewertung anfordern"** / **"Unverbindliches Angebot erhalten"** / **"Immobilienwert ermitteln"**
- Formulierung muss Sicherheit vermitteln, nicht Geschwindigkeit

#### 7. TONALITAET: Nicht "unkompliziert + fair"
- Gebrauchtwaren: "Schnell, einfach, fair" (3 Worte genuegen)
- Immobilien: **"Sicher, transparent, wertschaetzend"**
- Der Eigentuemer gibt nicht "was Altes" ab -- er trennt sich von Substanz
- Kommunikation muss das respektieren

### Zusammenfassung: Der goldene Mittelweg

```
wirkaufendeinauto.de          wirkaufendeineimmobilie.de          engelvoelkers.com
|                             |                                    |
Funktional                    HIER                                 Premium
Laut                          Klar + Warm                          Elegant
Du                            Sie (warm)                           Sie (formell)
Orange + Blau                 Gruen + Anthrazit                    Rot + Schwarz
Open Sans                     Serif + Sans Kombination             Eigene Schrift
Formular-First                Bild + Value Prop First              Immobilien-Karussell
"Jetzt verkaufen"             "Wert ermitteln"                     "Erfolgreich verkaufen"
Trustpilot                    Lokale Expertise + Referenzen        1000+ Standorte
```

**Der Kern:** wirkaufendeineimmobilie.de muss den "Wir kaufen"-Mechanismus (Einfachheit, Transparenz, Festpreis) behalten, aber visuell und tonal eine Stufe hoeher positionieren. Nicht billig-schnell wie Gebrauchtwaren. Nicht unerreichbar-exklusiv wie E&V. Sondern: **bodenstaendig-professionell mit Respekt vor dem Objekt.**
